## 面向公众的变化：preview-1 → v1.1.1

- **新增双语界面：** macOS 和 Windows 具备简体中文、英文与跟随系统；应用内即时切换，记忆选择，包含中英文使用说明。选择语言不会翻译实际 JSON 键和值，也不会自动提交编辑草稿。语言切换沿用本地完成的 1.1.0 行为，本轮没有修改其状态转换。
- **1.1.1 修复：** “空对象 / empty object”“空数组 / empty array”仅应匹配真正空的容器；Mac 自检检查中文翻译条目实际存在，避免缺资源时回退原文形成假阳性。两端构建入口加入文案完整性检查。
- **示例与发布：** 随包 JSON 示例的键名及说明值改成英文；两个独立实现、固定 Mac 图标、已入库 Windows ICO、MIT 和第三方声明继续保留。

Windows 分隔条的修复**已经存在于 `preview-1` 的 Windows 1.0.1 中**，不属于本次新修复。Windows 实机视觉确认仍须单独报告。
