**状态：本地准备中，未推送或发布 `v1.1.1`。** 基线为现有公开仓库 `main` 的 `7d7ab5be545357aa49a0f499cb76822f65f382f4`；`preview-1` 和[其验证记录](../PREVIEW_RELEASE.md)保持历史原样。Mac 为 1.1.1 (3)，Windows 为 1.1.1。源码、资源和三个本地候选包都指向同一产品与打包输入提交；下面是本轮实际结果。 [增量合并差异](1.1.1-migration.md)。

## 面向公众的变化：preview-1 → v1.1.1

- **新增双语界面：** macOS 和 Windows 具备简体中文、英文与跟随系统；应用内即时切换，记忆选择，包含中英文使用说明。选择语言不会翻译实际 JSON 键和值，也不会自动提交编辑草稿。语言切换沿用本地完成的 1.1.0 行为，本轮没有修改其状态转换。
- **1.1.1 修复：** “空对象 / empty object”“空数组 / empty array”仅应匹配真正空的容器；Mac 自检检查中文翻译条目实际存在，避免缺资源时回退原文形成假阳性。两端构建入口加入文案完整性检查。
- **示例与发布：** 随包 JSON 示例的键名及说明值改成英文；两个独立实现、固定 Mac 图标、已入库 Windows ICO、MIT 和第三方声明继续保留。

Windows 分隔条的修复**已经存在于 `preview-1` 的 Windows 1.0.1 中**，不属于本次新修复。Windows 实机视觉确认仍须单独报告。

## 历史 Mac AX 异常与晋升判断

`preview-1` 曾有一次辅助功能直接赋值后立即保存挂起；原因未明。本轮未复测历史 AX 直接赋值后立即保存路径，尚无修复证据；以后即使未复现，也不能直接写成已修复。1.1.1 核心测试不能冲抵它。当前最终包的正常聚焦输入、保存与重新打开已通过；若后续正常使用路径保存失败、数据损坏或静默覆盖，应停止正式版晋升。

**当前尚未达到完整正式版晋升条件。** 本地正常保存门槛通过，但尚无 1.1.1 最终 x64 附件的 Windows CI、后续获授权的远端预发布与验收。Windows ARM64 实机、真实 Windows GUI、分隔条视觉、输入法、DPI、macOS 最低版本和真实 Intel 设备仍未验证。已知限制和未验证项须在未来发布中如实保留；是否晋升由后续授权与实际验收决定。
