# JSON Dictionary Editor 1.1.1

基于现有公开预览 `preview-1`，本版保持独立的 macOS SwiftUI/AppKit 与 Windows Win32/C++ 实现、严格 JSON 数据规则，以及项目 MIT 许可和 `muyuzy123-pixel` 署名。

**从 preview-1 到 1.1.1：**

- 简体中文和英文界面；可选跟随系统，应用内即时切换并记忆选择。语言切换不翻译 JSON 数据，也不提交编辑草稿。
- 搜索“空对象 / empty object”“空数组 / empty array”只匹配真正空的容器；保留键名和值的普通文本匹配。
- macOS 自检确认简体中文条目实际随包载入，避免资源缺失被翻译回退掩盖；两端构建检查文案完整性。
- 示例 JSON 改用英文键名及说明值；提供中英文使用说明。

Windows 1.0.1 分隔条源码修复已存在于 `preview-1`，并非本版新增修复。本轮未复测历史 macOS AX 直接赋值后立即保存路径，尚无修复证据。完整 GUI、Windows 图标与分隔条实机视觉、Windows ARM64 和最低系统版本的验收范围，应以本次最终验证记录为准。

应用版本：macOS **1.1.1 (3)**、Windows **1.1.1**。[`v1.1.1` 预发布](https://github.com/muyuzy123-pixel/json-dictionary-editor/releases/tag/v1.1.1)提供三个英文文件名的 ZIP 与 `SHA256SUMS.txt`；三个包内的 `SOURCE.json` 均指向产品提交 `e9aa80312567baa43a34a26593c2001803ecca0e`。最终 x64 附件的 [Windows Server 2025 CLI 检查](https://github.com/muyuzy123-pixel/json-dictionary-editor/actions/runs/36206512065)通过；Windows 桌面 GUI 仍待验收，故尚未晋升正式版。
