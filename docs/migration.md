# 从历史交付到公开预览

原交付仅作只读输入：Mac 源码目录的 17 个文件和 Windows 源码目录选取的 13 个文件进入独立候选。App、EXE、ZIP、工具链、缓存、个人样例、截图帧、录像和完整会话日志均未作为源码历史导入。

## 已完成的整理

- 一个仓库包含 `macos/` 与 `windows/`，保留独立的应用和解析器；共享规则、样例及差异表单独维护。
- Mac 构建使用 `xcrun` 发现 SDK，独立输出目录和缓存，保留无签名构建入口；验证不修改旧交付物元数据。
- Windows 交叉构建要求显式工具链，原生构建与诊断检查失败退出码；提供独立核心测试入口。
- 来源未明 Windows ICO 已替换为有项目生成源码的七档资源。原 ICO 保留在原交付及本地审计备份，不纳入公开仓库。
- 原始验证记录完整备份到仓库之外。公开文件仅保留有明确日期和范围的摘要，避免将历史产物的署名、摘要或验收状态改写成当前结果。

## 首次发布调整

- 公开版权署名统一为 `muyuzy123-pixel`；标准 MIT 保持不变，第三方运行库保留独立声明。
- 两端版权资源更新，Bundle ID、Windows 内部标识和应用版本保持不变。
- 原 Mac ICNS 作为固定必要资源加入源码，避免当前系统重新渲染改变原图标字节；原图标生成器保留。Windows ICO 字节不变。
- 增加显式预览打包入口：Mac 在独立副本中 ad-hoc 签名，Windows 未签名；归档包含许可、使用说明、样例及源码提交信息。
- 增加一条只读权限的 Windows CI，只下载并测试最终 x64 预览包，不重建或启动 GUI。

发布使用候选自身的干净 Git 历史，不导入父工作区、本地审计或原交付历史。应用实现源文件没有因署名或发布整理重写。逐文件来源与当前摘要见 [file-manifest.tsv](file-manifest.tsv)，完整当前文件摘要见 [SHA256SUMS](../SHA256SUMS)。
